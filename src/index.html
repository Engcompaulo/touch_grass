Game Night Scoreboard

Set up the session, track the points, and let the game happen at the table.

1. Which games do you have?

Check off the games your group owns in the catalog and add any that aren't on the list.

Game catalog

Selected games

2. Who's playing?

Add 4 to 20 players to continue.

Registered players

3. How much is each game worth?

Set the point value for each selected game (a whole number from 1 to 1000). The default is 1 point.

4. Match order suggestion

Ask for a match order based on the games and the number of players. If the AI is unavailable, a local sequence is used.

5. Score tracking

When a match ends, pick the game and the winning player to add up the points.

6. Winner of the day
